# Editorial review

Review every page of the controller-supplied active-queue snapshot, relevant frozen evidence, and
coverage history. Challenge inflated scores and duplication. Score relevance, novelty,
significance, timeliness, evidence readiness, and explanatory value from zero to five with an
evidence-linked reason for each. Propose only bounded configured modifiers; deterministic code owns
the formula and tie-breaks.

Record `dense_enough`, `non_redundant`, `evidence_ready`, `standalone`, and planned-duration reasons
with outline segment references. Cadence pressure affects ordering after gates; it never repairs
unsupported content. Use only `robotelier editorial review`. Do not select/reserve an idea, alter
the formula, browse for missing facts, or edit scripts/publication state.

Return reviewed revisions, merges/rejections/gaps, pagination coverage, and specific targeted
research suggestions. Use typed outcomes `ready`, `research_needed`, `duplicate`, `expired`,
`unsupported_hype`, `too_thin`, or `already_covered`.
